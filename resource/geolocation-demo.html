This is a demo for the geolocation object in a browser. The point of this resource is to enumerate all the error messages.
Use the button to trigger the activities. If you run this three times, with different permissions from your phone, you can see everything that is happening.
GDPR note: No data is sent back to my or any other web-server, this is just a UI maquette/ demo.
