Concept

From the position that the internet would be better if “essential SPA in JS” wasn't mentioned or thought. In 2007, there where problems, and JS-SPA was a good solution THEN. Today there are many solutions, so JS-SPA isn't essential.

A JS minimalist approach leads to better accessibility on average, as there is more control to build #a11y and RWD and so-on. Less JS is routinely leads to less bandwidth needed, and faster load times. Storing application solutions in formats other than JS means it is easier to localise/ internationalise ~ IMO. Disclaimer: I use a large amount of JS and TS.

Requests

However, it would be easier when:

  • Various HTML validators are updated to understand DIALOG element. #leSigh.
  • Search HTML element was globally supported. As of 2024: this is available in Safari 17+
  • Forms in HTML supported encoding of JSON, to allow POST straight to a REST API. I am kind-of-doing this via JS fetch() and JSON features.
  • Web manifest file format extended to support listing ALL files deployed, as in common in other languages.
  • Forms had a cancel Button type. If we use less HTTP requests, we need 'Cancel' not an HTTP0.9 Anchor to other page. This should work similar to a Dialog.open=false. I can implement this in JS, each time for each form, but an architecture solution would be better.
  • Role attrib was allowed to have multiple items, example: a UL of LI and navigation elements is a list role, and its navigation role. The List role is probably less important.
  • The ARIA attribs were better wired in to the rest of HTML and CSS,
  • SPOILER HTML element, behaves similar to DETAILS/ SUMMARY 1.
  • There was a common agreed format for client-side localisation persistence. This item ignores a traditional DB in a server. Probably any early edition would use YaML. I see Vue has i18n block is SFC.
  • Maybe out of scope, but JS tools being encouraged to report unknown values in config files as unknown values

Some of these are my initial idea, some are imports from others. This list will be updated.
