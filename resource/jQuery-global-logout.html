Basic Idea for a JS tool

A browser can: close all tabs in a window; can close all windows; can resource limit runaway pages. A browser cannot tell if you want a given tab.
If a site/app designer thinks that a UI with user accounts should open many concurrent tabs, maybe the UX should undo the “open many tabs” when the consumer states that they are now no longer using the tabs (by logging out).

As with most of the stuff that I put into an article on here, I start with a literature search. As far as I found, every JS close() function is attached to a popup library. For example, an article from 2013 1.

By the time I thought about the requirement, I didn't see anyone using jQuery anymore; so there was no point in writing this code. Secondly, in JS, you can only close windows that are opened via JS... This doesn't suite many site architectures. I wish my bank would adopt something like this, rather than leaving advertising tabs lying around.
